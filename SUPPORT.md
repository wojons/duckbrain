# Support — DuckBrain Memory System

DuckBrain is a git-backed persistent memory system for AI agents providing DuckDB storage, MCP tools, HTTP API, and namespace management.

## Getting Help

- Documentation: See `docs/` directory for API reference and guides
- Issues: Report bugs via [GitHub Issues](https://github.com/wojonstech/duckbrain/issues)
- Discussions: For questions and feature requests, use [GitHub Discussions](https://github.com/wojonstech/duckbrain/discussions)

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | Yes (active)       |
| 0.x     | No (pre-release)   |
