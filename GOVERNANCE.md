# Governance

DuckBrain is a Nous Research project maintained by the Hermes Agent ecosystem.

## Decision Making

Project direction and architectural decisions are made by the project maintainers.
Feature proposals and significant changes should be discussed via GitHub issues
before implementation.

## Code of Conduct

This project adheres to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).
By participating, you are expected to uphold this code.

## Security

Security vulnerabilities should be reported privately as described in
[SECURITY.md](SECURITY.md). Do not file public issues for security concerns.

## Maintenance

This project uses the Coding Hermes autonomous development fleet for continuous
improvement. The `.coding-hermes/tasks.md` board is the single source of truth
for project state and task tracking.
